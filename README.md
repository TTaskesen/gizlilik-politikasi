# Kutular Gizlilik Politikası

Yayınlanan sayfa: <https://ttaskesen.github.io/gizlilik-politikasi/>

Bu bağımsız GitHub Pages deposu, **Kutular** oyununun mağazalarda kullanılacak gizlilik politikası sayfasını içerir.

Politika, oyunun kişisel veri toplamadığını; ilerleme, ayar, rekor, başarım ve yüzük bilgilerinin yalnızca cihazda tutulduğunu açıklar. Mağaza sağlayıcılarının kendi hesap, ödeme ve güvenlik işlemleri bu politikanın kapsamı dışındadır.
