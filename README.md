# Kutular Gizlilik Politikası

Yayınlanan sayfa: <https://ttaskesen.github.io/gizlilik-politikasi/>

Bu bağımsız GitHub Pages deposu, **Kutular** oyununun yayınlarında kullanılacak gizlilik politikası sayfasını içerir.

Politika, Kutular'ın kişisel veri toplamadığını; oyun ilerlemesi, oda kayıtları, rekorlar, başarımlar, yüzük bilgileri ve ayarların yalnızca cihazda tutulduğunu açıklar. Geliştirici hesabındaki ad Turgut Taskesen, geliştirici iletişimindeki ad Turgut Taşkesen'dir. Mağaza sağlayıcılarının kendi hesap, ödeme ve güvenlik işlemleri bu politikanın kapsamı dışındadır.
